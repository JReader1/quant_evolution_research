# Quantitative Order Flow Research

## Research Objective
Investigate whether historical order-flow
imbalance can predict short-term price movements.

## Research Questions
1. Which historical market characteristics predict relative stock performance?
2. Can machine-learning models outperform simpler statistical benchmarks?
3. Do predictive relationships persist across unseen time periods and stocks?
4. Can a market-neutral portfolio constructed from these predictions produce positive risk-adjusted returns after realistic transaction costs?
